# 🦌 Охота (Hunt Bot) - Telegram Hunting Game

Реалистичный охотничий симулятор с элементами RPG для Telegram. Исследуйте локации, охотьтесь на животных, выполняйте квесты и станьте легендарным охотником!

## ✨ Особенности

- **6 уникальных локаций**: Лес, Тайга, Горы, Степь, Болота, Глухой лес
- **Система прогресса**: Открывайте новые локации при достижении 80% прогресса
- **Боссы**: Уникальные боссы на каждой локации (доступны при 70% прогресса)
- **Система квестов**: Сюжетные и побочные задания
- **Навыки**: Прокачивайте меткость, скрытность и выносливость
- **Экономика**: Монеты и Telegram Stars для премиум-функций
- **Инвентарь**: Собирайте трофеи и ресурсы
- **Магазин**: Покупайте оружие, боеприпасы и приманки
- **Аукцион**: Торговля с другими игроками
- **Кулдауны**: Система восстановления энергии и кулдаунов

## 🛠 Технологический стек

- **Python 3.10+**
- **aiogram 3.x** - Telegram Bot API
- **SQLAlchemy 2.0** - ORM
- **aiosqlite** - Асинхронный драйвер SQLite
- **APScheduler** - Планировщик задач
- **Redis** - Кэширование (опционально)

## 📦 Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd huntbot
```

2. Создайте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

## ⚙️ Настройка

1. Скопируйте файл `.env.example` в `.env`:
```bash
cp .env.example .env
```

2. Отредактируйте `.env` файл:
```env
BOT_TOKEN=your_telegram_bot_token_here
DATABASE_URL=sqlite+aiosqlite:///./huntbot.db
REDIS_URL=redis://localhost:6379/0
ADMIN_IDS=123456789,987654321
```

3. Получите токен бота у [@BotFather](https://t.me/BotFather) в Telegram

4. (Опционально) Запустите Redis для кэширования:
```bash
redis-server
```

## 🚀 Запуск

1. Инициализируйте базу данных и заполните её данными:
```bash
python seed_data.py
```

2. Запустите бота:
```bash
python main.py
```

## 🎮 Игровые механики

### Энергия

- **Максимум**: 100 ед.
- **Пассивное восстановление**: +1 ед. каждые 5 минут
- **Активное восстановление**: +20 ед. за порцию мяса (команда `отдых`)
- **Затраты**:
  - Охота: 5 ед.
  - След: 3 ед.
  - Приманка: 4 ед.
  - Засада: 6 ед.
  - Переход: 5 ед.

### Охота

- **Базовый шанс попадания**: 70%
- **Модификаторы**:
  - Навык «Меткость»: +2% за уровень (макс. +30%)
  - Оружие: арбалет +5%, винтовка +10%
  - Прочность оружия <50%: –10%
  - Погода: –10%
- **Максимальный шанс**: 95%

### Редкость животных

| Редкость | Шанс | Множитель опыта | Множитель монет |
|----------|------|-----------------|-----------------|
| Обычная | 50% | ×1.0 | ×1.0 |
| Необычная | 25% | ×1.5 | ×1.5 |
| Редкая | 15% | ×2.5 | ×2.5 |
| Эпическая | 8% | ×4.0 | ×4.0 |
| Легендарная | 2% | ×7.0 | ×7.0 |

### Локации

1. **Лес** (стартовая) — зайцы, лисы, кабаны
2. **Тайга** — волки, рыси, лоси
3. **Горы** — горные козлы, барсы, грифоны
4. **Степь** — антилопы, львы, гепарды
5. **Болота** — кабаны, аллигаторы, цапли
6. **Глухой лес** — Великий лось (финальный босс)

### Навыки

- **Меткость**: +2% к шансу попадания за уровень
- **Скрытность**: +3% к шансу найти след за уровень
- **Выносливость**: +2 макс. энергии и -1% затрат энергии за уровень

## 💬 Команды

### Текстовые команды

- `/start` — Начать игру
- `/help` — Справка
- `хант` / `выстрел` — Охотиться
- `след` — Найти следы (+20% шанс редкого животного)
- `приманка [тип]` — Установить приманку (травоядная/хищная)
- `засада` — Засада (+30% шанс крупной добычи)
- `отдых [N]` — Отдохнуть (съесть N порций мяса)
- `/admin` — Панель администратора

### Меню (кнопки)

- 📍 Локации — просмотр и переход
- 🎒 Инвентарь — просмотр и управление предметами
- 🛒 Магазин — покупка снаряжения
- 📜 Квесты — список заданий
- 👤 Профиль — статистика и навыки
- 🎯 Навыки — прокачка характеристик
- 🏆 Аукцион — торговля
