# Как запустить notify_boss_kills.py на сервере

Этот скрипт нужно запустить **один раз** для отправки уведомлений игрокам, которые уже убили легендарных животных (боссов).

## Способ 1: Через docker exec (Рекомендуется)

После запуска бота через docker-compose:

```bash
# 1. Найти ID контейнера бота
docker ps

# 2. Запустить скрипт внутри контейнера
docker exec -it huntbot-bot-1 python notify_boss_kills.py

# Или если название контейнера другое:
docker exec -it <container_name> python notify_boss_kills.py
```

## Способ 2: Через docker-compose exec

```bash
# Находясь в папке с docker-compose.yml
docker-compose exec bot python notify_boss_kills.py
```

## Способ 3: Локально (если база данных доступна)

Если у вас есть доступ к базе данных с локальной машины:

```bash
# Активировать виртуальное окружение
.\venv\Scripts\activate

# Запустить скрипт
python notify_boss_kills.py
```

## Что делает скрипт

1. Находит все записи в таблице `hunt_logs` где `rarity = 'legendary'` и `is_successful = True`
2. Группирует по пользователям
3. Отправляет каждому пользователю уведомление со списком побежденных боссов
4. Выводит статистику в консоль

## Важно

- Скрипт безопасен, он только **читает** из базы и **отправляет сообщения**
- Можно запускать несколько раз - пользователи просто получат повторное уведомление
- После запуска скрипта бот уже будет показывать статус "✅ Босс побеждён" в интерфейсе локаций

## Проверка работы

После запуска в консоли вы увидите:
```
Найдено X пользователей с легендарными убийствами
Отправлено уведомление пользователю 123456789 (@username)
...
Всего отправлено уведомлений: X/Y
```

## Альтернатива - не запускать скрипт

Скрипт не обязателен! Он нужен только для уведомления **существующих** игроков. Для новых игроков:
- Статус босса будет обновляться автоматически при просмотре локаций
- После убийства легендарного животного сразу показывается "✅ Босс побеждён"
