# Автоматическое срабатывание ловушек

## Описание

Ловушки теперь срабатывают автоматически! Когда ловушка поймает животных, бот сразу отправит уведомление пользователю с результатами.

## Как работает

### 1. Установка ловушки
Пользователь пишет команду `ловушка`:
```
🪤 Капкан установлен!

⏰ Сработает в течение 30 минут
🎯 Поймает от 1 до 1 животных
⚡ Потрачено энергии: 13

💡 Когда ловушка сработает, вы получите уведомление автоматически!
```

### 2. Автоматическое срабатывание
- Фоновая задача проверяет активные ловушки каждые 30 секунд
- Когда ловушка готова (прошло время), она срабатывает
- Бот автоматически отправляет сообщение пользователю

### 3. Результат
Пользователь получает сообщение:
```
🎉 Ловушка сработала!

🪤 Капкан
🦌 Поймано животных: 2

Пойманные животные:
1. 🟢 🦌 Благородный олень (45.3 кг, uncommon)
2. ⚪ 🐰 Заяц (3.2 кг, common)

📊 Общие награды:
• +150 опыта
• +75 монет

Добыча:
• 5x Мясо
• 2x Шкура

📍 Локация: 🌲 Лес
⚡ Энергия: 87/100
```

## Технические детали

### Новые файлы:
- `bot/tasks/trap_checker.py` - фоновая задача проверки ловушек
- `bot/tasks/__init__.py` - инициализация модуля tasks

### Измененные файлы:
- `main.py` - запуск фоновой задачи
- `bot/handlers/trap.py` - убрана логика получения результатов вручную
- `bot/handlers/common.py` - обновлена справка

### Логика:

1. **trap_checker_loop()** - основной цикл, работает в фоне
2. **check_active_traps()** - проверяет всех пользователей с активными ловушками
3. **trigger_trap_catch()** - обрабатывает ловушку (ловит животных, начисляет награды)
4. **send_trap_results_to_user()** - отправляет результаты пользователю через bot.send_message()

### Интервал проверки:
- Каждые **30 секунд**
- Минимальная задержка: ~0 сек (сработает сразу после готовности)
- Максимальная задержка: ~30 сек

## Запуск

```bash
docker-compose up -d --build
```

Фоновая задача запустится автоматически вместе с ботом!

## Проверка работы

В логах будет:
```
INFO:bot.tasks.trap_checker:[TRAP_CHECKER] Started trap checker background task
INFO:bot.tasks.trap_checker:[TRAP_CHECKER] Checking 2 active traps
INFO:bot.tasks.trap_checker:[TRAP_CHECKER] Triggering trap for user 123456789
INFO:bot.tasks.trap_checker:[TRAP_CHECKER] Sent trap results to user 123456789
```

## Обработка ошибок

- Если пользователь заблокировал бота - ошибка логируется, проверка продолжается
- Если база недоступна - задача переподключится через 30 сек
- При остановке бота - задача корректно завершается
